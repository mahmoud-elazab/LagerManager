Implemented behavior
Valid successful responses require a nonempty token string without whitespace and tokenType Bearer. Tokens remain only in React state; the signed-in placeholder does not render them. Password values are sent without trimming or modification and cleared after successful login. Logout clears the session without any backend logout request. A fresh app mount/page refresh starts signed out. No routing, UI/global-state libraries, CRUD screens, registration, refresh tokens or additional API endpoints.
No backend source/security/CORS changes, real-user authentication, database operations, global installations or Git commands.
